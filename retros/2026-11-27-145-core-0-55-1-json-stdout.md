# Retro: #145, every generator on core 0.55.1 (PR #146)

## 1. Summary

#145 asked us to move every stock generator from core 0.54.0 to the newest core, so that `skmtc generate --json` prints only JSON for their users. The fix behind this was skmtc/skmtc#472. PR #146 pins core 0.55.1, lang-typescript 0.15.13 and lang-kotlin 0.11.47, and gives the 16 published packages a patch bump. No generator code changed. The follow-on step showed the result on JSR: with gen-zod 0.6.2, `generate --json` exits 0 and `jq` parses all of stdout.
The run took 17m 59s (14m 53s of agent time) and cost an estimated $4.78. It used 20,740 input tokens, 7.37M cached tokens and 48,429 output tokens.
`implement` cost the most: 10m and $2.68. About half of that went into reading and editing 19 deno.json files by hand, roughly 45 tool calls in total. The cascade script could have done it with one command.

## 3. Keep

- The removal test on `test-support/test/workspace.test.ts`: set one pin back to 0.54.0, see both the pin test and the lockfile test fail, then run `deno install` to clean the lockfile. Write it down in the skmtc-generator skill's `references/finish.md` for pin moves.
- Reproducing locally before the release: point a temporary project's `.skmtc/<p>/deno.json` at the worktree's `mod.ts` files. This showed the done-when result before anything was published. Write it down in the skmtc-debug skill.

## 4. Deferred

- `deno.json` `tasks.publish`: gen-shadcn-form is published before gen-shadcn-select, and gen-fetch-example is left out. A maintainer who publishes by hand meets this. Raised in the self-review; see #59.
- gen-zod, gen-valibot and gen-arktype all register `pet` at `@/types/pet.generated.ts` by default. A project that installs more than one of them fails with "Registered definition mismatch" and writes 0 files. The follow-on found it while installing all 16 generators.
- Root `deno lint` reports 7 ban-unused-ignore errors (gen-effect-schema/src/coercion.ts:14, Effect.ts:102, gen-md-docs/src/lang/MdFile.ts:63-90, test-support/checkGenerated.ts:1) that per-package lint does not. An agent who follows CLAUDE.md meets them.
- `deno fmt --check` reports 468 unformatted files across the repository. CI does not gate on it. An agent who runs `deno fmt` would get a huge diff.
- Deno's 24-hour minimum dependency age delays new generator releases for users with default settings. Nobody has checked this beyond the follow-on's CLI install.
